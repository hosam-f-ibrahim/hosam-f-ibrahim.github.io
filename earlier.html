intelliSYS add-ons 2019–2021

Data Enrichment (later FIU360 Connect)

Oct 2019 – Jan 2020 · intelliSYS Solutions & Consulting

I architected an extensible .NET/C# add-on suite that enriches AML reports with data from financial, government and open sources, removing manual data gathering and increasing data security and accuracy.

It acquires data automatically when the FIU receives a report or when an analyst asks, which cut acquisition latency by 99%. Parallel, multithreaded ETL pipelines cleanse and normalize what comes back with 99% data accuracy, and validation, error handling and retry logic reduced enrichment failures by more than 90%. Data is secured in transit with TLS, health is monitored in Application Insights, and I worked with third-party API providers on data coverage and SLA compliance.

I later continued its design and development as FIU360 Connect, an add-on that extends FIU360 and other existing FIU systems without changing their code base.

Technologies: C#/.NET; Microsoft SQL Server; REST APIs and web services; ETL

Data Visualization (enhanced visualization)

Jan 2020 – Jul 2021 · intelliSYS Solutions & Consulting

I architected a scalable .NET/C# framework that renders every object and relationship in the database, and led its development. Together with data enrichment, it let analysts follow relationships and flows directly instead of requesting data from government institutions and entering it by hand, reducing analyst effort by 90%.

It brings interactive dashboards with drill-down and filters, dynamic connectors that map relationships across databases, REST services for real-time data and graphing components for complex entity networks. Pre-aggregating relationship data in SQL Server views and stored procedures cut load times by 50%, and CI/CD pipelines in Azure DevOps delivered updates with zero downtime.

It is an add-on that extends FIU360 and other existing FIU systems without changing their code base.

Technologies: C#/.NET; Microsoft SQL Server; REST APIs and web services; DevExpress
